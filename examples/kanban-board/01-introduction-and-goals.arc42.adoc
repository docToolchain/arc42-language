== 1.1 Requirements Overview

The Kanban Board is a multi-tenant team collaboration tool that enables software development
teams to manage work using visual boards, columns, and cards. Each tenant (organisation) has
isolated data and can configure their own boards independently.

Key functional requirements:

* Teams can create and manage boards with customisable columns (e.g. To Do, In Progress, Done).
* Cards represent work items and can be moved between columns via drag-and-drop.
* Multiple team members can collaborate on boards in real time.
* Notifications are sent to relevant team members when cards are updated or moved.
* Administrators manage tenant settings, user accounts, and access control.
* The system supports both cloud-hosted and on-premise deployments.
