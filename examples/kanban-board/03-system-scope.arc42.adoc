= System Scope and Context

This chapter defines the external actors that interact with the Kanban Board application.

== Board User

Board users access the system through the web frontend and the main API endpoint to manage their kanban boards.

[source,arc42]
----
:::actor
id: actor-user
title: Board User
type: person
requires: if-api-gateway, if-frontend-web
:::
----

== System Administrator

System administrators access the system through the admin frontend and API for system configuration and monitoring.

[source,arc42]
----
:::actor
id: actor-admin
title: System Administrator
type: person
requires: if-api-gateway, if-frontend-admin
:::
----
