= Deployment View

This chapter describes the physical deployment of the system across infrastructure.

== Production Environment

The Production Environment hosts all system components.

[source,arc42]
----
:::deployment-node
id: dn-production
title: Production Environment
type: environment
hosts: bb-web-frontend, bb-admin-frontend, bb-api-gateway, bb-board-service, bb-auth-service, bb-notification-service
:::
----

== Web Frontend Server

The Web Frontend Server hosts the web and admin frontend applications.

[source,arc42]
----
:::deployment-node
id: dn-web-frontend
title: Web Frontend Server
type: server
hosts: bb-web-frontend, bb-admin-frontend
parent: dn-production
:::
----
